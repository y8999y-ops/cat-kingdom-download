# 疊疊看！三角形分類：交接說明

這份說明給之後接手修改遊戲的人（或 Claude）看。內容整理自最初和老師討論、製作的過程。

## 這是什麼

- 國小五年級數學的互動教學遊戲：配對**全等三角形**，再依角、邊**分類**。
- 用平板操作，學生掃 QR code 就能玩，不用安裝或登入，也不收集任何資料。
- 一次大約玩 **10 分鐘**。
- 網址：https://y8999y-ops.github.io/cat-kingdom-download/triangle/
  - 由 GitHub Pages 從 `main` 分支的根目錄發布。
  - `main` 一更新，網站就自動更新；網址不變，QR code 也不用換。

## 老師確定的需求

- 重點是**分類觀念**：銳角／直角／鈍角，正三角形／等腰／不等邊。
- 每一頁有一堆三角形，學生用手指**滑動、旋轉**（也可以翻面）來操作。
- **疊疊看**：把三角形疊到全等的另一個上面，疊對了就會**變透明**。
- 其他細節由 Claude 建議、老師同意：
  - 五年級課本用詞：全等、疊合、對應
  - 先配對、再分類
  - 小貓引導員
  - 不計時，用星星計分
- 2026-10 老師追加：字放大、不要雙指旋轉（改成一根手指拖圓圈）、三顆星放寬、疊合要對得很齊、不要音效。
  - 可以填座號

## 遊戲流程

1. 首頁：玩法說明、座號（可不填）、開始按鈕。
2. 關卡定義在 `PAGES` 陣列：
   - **練習**（`tutorial`）：一組等腰直角三角形，只練疊合，沒有分類。
   - **第 1 關**（`angle`）：4 組全等加 1 個干擾題，分到「銳角／直角／鈍角」三個籃子。
   - **第 2 關**（`side`）：4 組加 1 個干擾題，分到「正三角形／等腰／不等邊」。
     正三角形放進「等腰」不算錯，小貓會說明正三角形是特別的等腰三角形。
   - **第 3 關**（`both`）：5 組加 1 個干擾題，分進「等腰／不等邊 × 銳角／直角／鈍角」的 2×3 格子（這關沒有正三角形）。
3. 每關結束：星星（錯 0～1 次 3 顆、2～4 次 2 顆、5 次以上 1 顆，`starsFor()`）、錯誤次數、時間，並說明干擾題為什麼沒有全等的朋友。
4. 最後成績頁：座號、各關星星、總時間，可以「再玩一次」（跳過練習）或回首頁。

## 操作和判斷規則（`index.html` 內）

- **拖曳**：一根手指。一次只處理一根手指，另一隻手碰到螢幕會被忽略。
- **旋轉**：右側 ↺ ↻ 按鈕每次 30°；或拖動選取三角形旁的**橘色圓圈**（`#handle`、`drawHandle()`）繞圈，每 15° 一格。
  已經拿掉雙指旋轉（老師反映不好操作），不要加回去。
- **翻面**：⇋ 按鈕（`scale(-1,1)`，有翻牌動畫）。
- **出題**：`LIB` 是各類三角形的角度題庫；`genSpecs()` 每關隨機出題。
  - 各組大小從 0.8～1.2 中隨機分配，而且互不相同。
  - 干擾題有兩種：同形狀但放大 1.25 倍或縮小 0.72 倍，或同類但角度不同。
  - 銳角題最大角不超過 80°，鈍角題最小也有 105°，避免肉眼難以判斷。
- **配對**（`checkDrop()`）：
  - 放下時找最近的自由三角形。
  - 全等用三邊排序比對（`congruent()`）；對齊用頂點距離，6 種對應方式取最小值，門檻是邊長的 12%（`ALIGN_TOL`、`alignError()`）。老師要求要對得很齊才能疊合。
  - 全等又對齊：吸附並變成半透明的一組（`.piece.pair`，`fill-opacity .32`，綠色虛線框）。
  - 全等但沒對齊：不算錯。方向已經對了就提示「再對準一點」，不然提示「轉一轉、翻一翻」。
  - 不全等：算錯一次，提示「大小不一樣」或「形狀不一樣」，並把三角形推開。
  - 按旋轉、翻面按鈕之後也會靜默檢查一次，所以學生可以先疊上去再轉。
- **分類**（`classify()`）：
  - 把一組拖到籃子上，答對會縮成小圖示放進籃子。
  - 答錯算錯一次，並在三角形上顯示記號約 4.5 秒：藍框是直角、紅色扇形是鈍角、綠色扇形是銳角、紫色短線是等長的邊。
- **提示**：按 💡，或 30 秒沒有操作，會讓一組全等的三角形閃爍；沒有自由三角形時，改顯示記號。
- **其他**：
  - 沒有音效（老師要求拿掉）。
  - 用了 `touch-action: none` 等設定，防止平板誤觸縮放。

### 已經修過、不要改回去的地方

- 小貓對話框 `#say` 是**固定高度**（平板 140px、手機 140px）。文字長短不能改變版面高度，否則拖曳中桌面會位移，三角形會錯位。
  放大字之後，第 3 關分錯時的提示最長（4 行），改字體或高度後要確認它在三種尺寸都放得下。
- `say()` 會把內容包在 `<span>` 裡，因為 `#say` 是 flex 容器，不包的話粗體或彩色字會把文字切斷。
- 星星的灰色樣式 `.off` 是全域的，最後成績表才會正確顯示幾顆星。
- 只有真的拖動超過 8px 才檢查配對；單純點一下只是選取。

## 測試方式

用 Playwright（Chromium）分別在 iPad 橫式（1024×768）、iPad 直式（768×1024）、手機（390×844）三種尺寸，從頭玩到最後成績頁：

- 用真實的滑鼠拖曳和按鈕點擊來配對、分類。
- 包含故意疊錯、故意分錯各一次。
- 確認沒有 JS 錯誤，並截圖檢查版面。

遊戲的全域變數和函式（`pieces`、`byId()`、`congruent()`、`keyOf()` 等）可以在 `page.evaluate` 裡直接使用。
