# 疊疊看！三角形分類：交接說明

這份說明給之後接手修改遊戲的人（或 Claude）看。內容整理自最初和老師討論、製作的過程。

## 這是什麼

- 國小五年級數學的互動教學遊戲：依邊、角**分類**三角形，配對**全等三角形**，再找**對應點、對應邊、對應角**。
- 用平板操作，學生掃 QR code 就能玩，不用安裝或登入，也不收集任何資料。
- 一次大約玩 **10～12 分鐘**。
- 網址：https://y8999y-ops.github.io/cat-kingdom-download/triangle/
  - 由 GitHub Pages 從 `main` 分支的根目錄發布。
  - `main` 一更新，網站就自動更新；網址不變，QR code 也不用換。

## 老師確定的需求

- 重點是**分類觀念**：銳角／直角／鈍角，正三角形／等腰／不等邊。
- 每一頁有一堆三角形，學生用手指**滑動、旋轉**（也可以翻面）來操作。
- **疊疊看**：把三角形疊到全等的另一個上面，疊對了就會**變透明**。
- 其他細節由 Claude 建議、老師同意：
  - 五年級課本用詞：全等、疊合、對應
  - 先配對、再分類
  - 小貓引導員
  - 不計時，用星星計分
  - 可以填座號
- 2026-10-28 老師追加（第 1 次）：字放大、加上一根手指拖圓圈旋轉、三顆星放寬、疊合要對得很齊、不要音效。
- 2026-10-28 老師追加（第 2 次）：雙指旋轉也要保留、疊合方向誤差約 5° 以內、不等邊三角形沒翻面不能疊合、字再放大、提示要會閃、配對好的一組要更明顯。
- 2026-10-28 老師追加（第 3 次）：第 1 關改成用邊分類、第 2 關用角分類，**都不用配對全等**；後面保留疊合再分類；新增一關練習**對應邊、對應點**；三角形放大。
  第 3 關只保留「角和邊一起看」那一關。原本「先疊合再用角分類」「先疊合再用邊分類」兩關拿掉，避免和第 1、2 關重複，也讓總時間維持在約 10 分鐘。老師要加回來的話，再加到 `PAGES`。

## 遊戲流程

1. 首頁：玩法說明、座號（可不填）、開始按鈕。
2. 關卡定義在 `PAGES` 陣列，依序是：
   - **第 1 關**（`side`，`direct: true`）：6 個三角形（正三角形、等腰、不等邊各 2 個），直接拖進「正三角形／等腰／不等邊」籃子，不用配對。
     正三角形放進「等腰」不算錯，小貓會說明正三角形是特別的等腰三角形。
   - **第 2 關**（`angle`，`direct: true`）：6 個三角形（銳角、直角、鈍角各 2 個），直接拖進「銳角／直角／鈍角」籃子。
   - **練習**（`tutorial`）：一組等腰直角三角形，只練疊合，為第 3 關做準備。
   - **第 3 關**（`both`）：5 組全等加 1 個干擾題，疊合成一組後，分進「等腰／不等邊 × 銳角／直角／鈍角」的 2×3 格子（這關沒有正三角形）。
   - **第 4 關**（`corr`）：找對應，見下面。
3. 每關結束：星星（錯 0～1 次 3 顆、2～4 次 2 顆、5 次以上 1 顆，`starsFor()`）、錯誤次數、時間；第 3 關會說明干擾題為什麼沒有全等的朋友。
4. 最後成績頁：座號、各關星星、總時間，可以「再玩一次」（從第 1 關開始，跳過練習，`replay`）或回首頁。

### 第 4 關：找對應（`startCorrRound()`、`askCorr()`、`answerCorr()`）

- 共 3 組，依序是不等邊的銳角、直角、鈍角三角形。每組兩個全等三角形，頂點標 A B C 和 D E F（字母放在頂點外側，反向旋轉保持正立）。
- 每組 3 題：A B C 上某個點的**對應點**、某條邊的**對應邊**、某個角的**對應角**，學生在 D E F 那個三角形上點答案。
  題目的部分在 A B C 上用橘色閃爍標出；答對後兩邊都上色（點：粉紅圈、邊：藍線、角：綠色扇形）。
- 對應關係用「角一樣大」決定（`corr.map`）；邊 k 是頂點 k 對面的邊，所以對應邊就是對應頂點對面的邊。
- 兩個三角形都可以拖、轉、翻，學生可以疊上去比比看；這一關沒有疊合吸附。
- 點一下（沒有拖動超過 8px）才算作答；點到 A B C 那個、或點錯種類（題目問邊卻點頂點）只提示，不算錯；點錯答案算錯一次。
- 提示：讓正確答案閃黃光，不算錯。

## 操作和判斷規則（`index.html` 內）

- **拖曳**：一根手指。超過兩根手指的觸控會被忽略。
- **旋轉**：三種方式都要保留（老師要求）：
  - 右側 ↺ ↻ 按鈕，每次 30°。
  - 拖動選取三角形旁的**橘色圓圈**（`#handle`、`drawHandle()`）繞圈，每 15° 一格。
  - 兩指旋轉（`gesture`），放開後吸附到 15° 的倍數。
- **翻面**：⇋ 按鈕（`scale(-1,1)`，有翻牌動畫）。
- **出題**：`LIB` 是各類三角形的角度題庫；`genSpecs()` 每關隨機出題。
  - 各組大小從 0.8～1.2 中隨機分配，而且互不相同。
  - 三角形的大小（`measure()`）：最長邊約是格子的 70%，第 4 關約 62%（只有兩個，最大到 300px）。
    擺好後用 `fitIn()` 把整個三角形推回桌面內，右邊留給工具列（`TOOL_W`）；第 4 關多留 52px 給頂點字母。
  - 干擾題有兩種：同形狀但放大 1.25 倍或縮小 0.72 倍，或同類但角度不同。
  - 銳角題最大角不超過 80°，鈍角題最小也有 105°，避免肉眼難以判斷。
- **配對**（`checkDrop()`）：
  - 放下時找最近的自由三角形。
  - 全等用三邊排序比對（`congruent()`）。
  - 對齊（`alignInfo()`、`isAligned()`）只看**對應頂點**，也就是對應的角要一樣大。條件是頂點誤差小於邊長的 12%（`ALIGN_TOL`），而且方向誤差不超過 5°（`ALIGN_DEG`）。老師要求要對得很齊才能疊合。
    以前任意 6 種頂點對應都算，結果有 7 種不等邊三角形沒翻面也能疊合，已經修正，不要改回去。
    等腰、正三角形左右對稱，翻不翻面都能疊合，這是對的。
  - 全等又對齊：吸附並變成半透明的一組（`.piece.pair`，`fill-opacity .32`）。外面加綠色光暈、粗綠框，重心有 ✓（`.badge`，反向旋轉才不會轉歪），和還沒配對的明顯不同。
  - 全等但沒對齊：不算錯。方向已經對了就提示「再對準一點」，不然提示「轉一轉、翻一翻」。
  - 不全等：算錯一次，提示「大小不一樣」或「形狀不一樣」，並把三角形推開。
  - 按旋轉、翻面按鈕之後也會靜默檢查一次，所以學生可以先疊上去再轉。
- **分類**（`classify()`）：
  - 第 1、2 關（`direct`）直接把單個三角形拖到籃子上；第 3 關要先疊合成一組才能放。答對會縮成小圖示放進籃子。
  - `checkDrop()` 在 `direct` 和 `corr` 關卡直接略過，不做疊合判斷。
  - 答錯算錯一次，並在三角形上顯示記號約 4.5 秒：藍框是直角、紅色扇形是鈍角、綠色扇形是銳角、紫色短線是等長的邊。
- **提示**：按 💡，或 30 秒沒有操作。第 1、2 關：讓一個三角形閃黃光並顯示記號。第 4 關：讓正確答案閃黃光。第 3 關和練習：讓一組全等的三角形閃黃光（有選取的話，優先找它的朋友），並移到最上層；沒有自由三角形時，改讓配對好的一組閃爍並顯示記號。
- **其他**：
  - 沒有音效（老師要求拿掉）。
  - 用了 `touch-action: none` 等設定，防止平板誤觸縮放。

### 已經修過、不要改回去的地方

- 小貓對話框 `#say` 是**固定高度**（平板 156px、手機 150px）。文字長短不能改變版面高度，否則拖曳中桌面會位移，三角形會錯位。
  第 3 關分錯時的提示最長，改字體、高度或提示文字後，要確認它在三種尺寸都放得下。
- 閃爍（`.pulse`、`.pop`）是用三角形外面一圈 `polygon.glow` 的 opacity 動畫做的。
  **不要用 CSS `filter`**：iPad Safari 不支援 SVG 元素上的 filter，以前提示在 iPad 上完全不會閃。
- `say()` 會把內容包在 `<span>` 裡，因為 `#say` 是 flex 容器，不包的話粗體或彩色字會把文字切斷。
- 星星的灰色樣式 `.off` 是全域的，最後成績表才會正確顯示幾顆星。
- 只有真的拖動超過 8px 才檢查配對；單純點一下只是選取。

## 測試方式

用 Playwright（Chromium），或 Claude 桌面版內建的瀏覽器分別在 iPad 橫式（1024×768）、iPad 直式（768×1024）、手機（390×844）三種尺寸，從頭玩到最後成績頁：

- 用真實的滑鼠拖曳和按鈕點擊來配對、分類。
- 包含故意疊錯、故意分錯各一次。
- 確認沒有 JS 錯誤，並截圖檢查版面。
- 瀏覽器分頁在背景時，CSS 動畫和 `requestAnimationFrame` 會暫停，這時旋轉的吸附、閃爍看起來會像壞掉。
  測試時可以在頁面裡暫時把 `requestAnimationFrame` 換成 `setTimeout`，或用 `getAnimations()` 檢查動畫有沒有掛上去。
- 兩指旋轉可以用兩個不同 `pointerId` 的 `PointerEvent` 模擬。

遊戲的全域變數和函式（`pieces`、`byId()`、`congruent()`、`keyOf()` 等）可以在 `page.evaluate` 裡直接使用。
